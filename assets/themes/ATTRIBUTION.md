## Detailed illustrated scenes and charms (2026-10-29)

`art/sakura-atelier.webp`, `art/starlit-tide.webp` and the four files under `charms/` were created specifically for this project using the built-in image_gen tool. They are AI-generated illustrations, not downloads of Pixiv, game or QQ artwork. The themes use complete paintings rather than composed stock icons. Transparent alpha is preserved for charms; only responsive resampling and WebP encoding are applied. Full prompts are retained in GENERATED-ART.json. Original generated PNGs remain in the workspace generated_images folder. Background thumbnails use the same painting and CSS position as the page; the full-art dialog shows the uncropped painting.

## Simplified artwork revision

Current recommended backgrounds use `art/sakura-atelier-v2.webp` and `art/starlit-tide-v2.webp`, generated with fewer objects and broad areas of quiet sky. Current character stickers are `charms/exam-pony.webp`, `hello-puppy.webp`, `quiet-kitten.webp` and `quiet-fox.webp`. The pony and puppy were redrawn with image_gen from user-supplied visual references; the kitten and fox follow the supplied puppy's simplified style. Reference artwork remains the property of its respective rights holder; these are not represented as independently licensed stock. Original complex generated ornaments remain available only to existing saved preferences. Full generation and refinement prompts are retained in GENERATED-ART.json. Encoding preserves each sticker's original transparency and aspect ratio.

## Study shore collection (2026-10-30)

The `study-shore` preset now uses `art/exam-good-luck.webp` and `art/exam-good-luck-wide.webp`: original exam-good-luck illustrations generated with the built-in image_gen tool. The existing pony charm supplied color and simplicity guidance, then the generated concept supplied the composition reference for 4:9 phone and landscape companions. Only proportional thumbnail resampling and WebP encoding are applied. The existing `charms/exam-pony.webp` is unchanged. The full-art viewer and actual wallpaper use the same viewport breakpoint. Full prompts and dimensions are recorded in GENERATED-ART.json. The earlier lakeshore originals `art/study-shore.webp` and `art/study-shore-wide.webp` remain in the source archive but are no longer the preset's active artwork.

## Pastel storybook collections (2026-10-30)

Backgrounds `woolly-meadow`, `summer-float`, `butter-daisy` and `lotus-pond`, plus transparent charms `little-lamb`, `float-bunny`, `daisy-bear` and `pond-duck`, were created using the built-in image_gen tool with two user-supplied screenshots as visual references for soft pastoral and summer-pool styling. The scenes and character arrangements are newly generated; screenshot UI, membership badges and labels are not incorporated. This does not claim a stock-art license for the reference screenshots. Prompts, reference filenames, image dimensions and output paths are recorded in GENERATED-ART.json. Site versions use proportional resampling and WebP compression; transparent alpha is preserved for charms.
