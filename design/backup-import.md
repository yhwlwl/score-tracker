# JSON 备份导入

账号 → 数据 → 导入恢复。接受成绩轨迹导出的 JSON 完整备份，兼容旧版无 backupVersion 的文件；CSV/TXT 是查看与分享格式，不用于恢复。上限 8 MB、1000 场考试。

文件先在本地校验，然后由已登录的导入接口重新校验并只读预览。确认后，单个数据库事务导入新考试，任何一项失败都回滚。源文件中的账号、用户编号和登录信息不参与授权；目标账号仅由有效会话决定，考试和组合关联使用新编号。

保留最终分、原始分、满分、0 与 null、隐藏状态、分类、起止日期、各层级排名与位比、组合关联/排名/均分、考后反思和已有题型明细。新 JSON 备份补入长期目标及默认参考人数，不包含密码、会话、私有扫描件或 AI 报告。

默认仅新增，保留已有成绩。来源编号已导入、编号属于当前账号，或名称/日期/分类/科目集合相同的考试均跳过；不会覆盖更晚编辑。重试不会重复导入。相同名称而选科不同的组合重命名保留，引用和默认人数自动重映射。同名同日期却确实不同的考试，应先在备份中区分考试名称，再预览导入。

科目配置仅补齐缺项；勾选“同时恢复设置”后，覆盖备份内科目的默认满分、分类、目标与默认参考人数。旧备份未提供的目标/人数设置保留。预览与导入均绑定当前账号，切换账号会丢弃未提交文件；导入时重新计算重复数量，最终结果以提交响应为准。

## 验证

- `design/test-backup-import.cjs`：真实 Edge handler → 隔离 PostgreSQL RPC、真实前端导出/导入界面，覆盖零/未知、原始/赋分、隐藏、跨账号源 ID、均分/组合/目标重映射、旧备份、内容确认、重复重试、同名保护、失败整批回滚和 anon/authenticated 无 RPC 权限。
- 原有考试均分保存/导出回归、同域代理、bundle 一致性、Cloudflare 构建。
- `node design/build-backup-import-preview.cjs` 生成合成数据验收页 `/design/backup-import-qa/`。页面明确使用请求模拟，不访问真实账号或生产数据库。
- 当前环境的本地 Chromium 被 socket 权限阻止，云浏览器也无法访问本地预览端口，因此不声称完成浏览器视觉验收。DOM 交互与数据链路已通过上述测试。

发布顺序：数据库 migration → 新建 `score-tracker-import` Edge Function（自有会话鉴权，verify_jwt=false）→ push main 触发 Pages。新接口独立部署，不替换线上可能比 main 更新的成绩/识图接口。
