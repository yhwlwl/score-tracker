# 试卷复盘真实评测记录

时间：2026-10-19至20日，北京时间。目的：验证通用产品改动，而非把评测答案写进提示词。

## 方法

- 使用用户授权的六张原始物理资料重新提交真实模型调用；先独立分析原卷和作答，再比对报告。
- 另用两页独立生成的英语阅读/写作样例实测。样例包含明确教师大题分、无小问分，以及可核验的材料依据、句数和语法问题。
- 产品提示词不包含这份物理试卷的分数、正确选项、公式结果、题号或订正结论。真实原图、姓名、学校、账号、完整作答与会话凭据不进入仓库。
- 接口/数据库/前端夹具测试验证权限、计分与恢复，不作为学科正确率证明。

## 观察和处理

| 项目 | 观察 | 结论 |
| --- | --- | --- |
| 旧请求配置 | 复用了成绩识图的关闭思考参数，整卷只有90秒预算 | 新功能隔离配置，按阶段和题目分配推理预算 |
| 首次开启高推理 | 转录阶段24576输出tokens中，21915用于推理，回答被截断 | 转录轻推理，失分/复杂题深推理，满分题轻核验 |
| 批改分层级 | 旧报告拆分了不存在的小问得分，合计也不符 | 新合同只保留实际计分层级，未知保持null |
| 合计与归属 | 一次读取合计65/100，但个别填涂与逐题红分仍错位 | 合计不是准确性保证；增加不锚定前次结果的独立读取，不一致的字段隔离 |
| 已有能力 | 新报告保留分离条件、分离位置及同步轨道高度的正确推导 | 有进步，不再笼统要求重学整个单元 |
| 复杂题帮助 | 新报告可给出整体能量清单、连接状态变化与后续分段，数值可独立验证 | 有信息增量，能帮助学生从正确前缀继续作答 |
| 最终总结 | 曾新增逐题解答里没有的错误条件变化 | 行动任务和验收改由对应逐题诊断字段投影，模型只负责排序与说明 |
| 范围与图像 | 仍漏用粗糙程度相同的条件收紧范围，图像截距符号也有错误 | 语义验收未通过；不能宣布已达全量开放标准 |
| 英语通用性 | 找到材料依据错误、未满足句数、缺系动词；保留正确提取的信息，不拆教师分 | 初步证明分析路径不限于物理，但样本量不足以证明多科可靠性 |

## 耗时与推理用量

一次中间版本完成整卷用时691431ms，供应商回报94410推理tokens。最终完整复测记录包含14次实际模型调用和两次超时后的同请求继续；供应商已回报132214推理tokens，模型请求累计1058554ms（含超时），创建至完成1579320ms（另含调试与恢复间隔）。不能把后者当作纯模型思考时间，也不能把更多tokens当作正确性的证明。

每次调用有独立时间、阶段、模型、推理设置、提示词摘要和供应商用量。超时未回报的用量保持未知。原始模型回答和确定性报告投影分别保留，未人工替换AI解答来制造通过结果。

## 交付判断

通用报告结构、证据约束、独立读取、分批推理、恢复和记录已实现；真实报告已经比旧版更有帮助，仍存在填涂读取、图示解释和条件使用不完整的问题。保留Beta与手动核对，暂不认定为免核对的自动诊断。后续验收应扩充多用户多科资料并对比图文与推理能力更稳定的模型，而非只继续增加提示词或等待时间。
