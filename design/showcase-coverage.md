# showcase 演示覆盖

所有带【演示】的记录均为合成样例。六科数据有独立的涨跌与波动，难度来自显式标注，不由得分推断。

账号保留原有 12 场考试，另有 12 场六科考试和 4 场专项小测，共 28 场。演示部分含 76 条科目成绩、407 条题型记录，每条均有题号/位置和难度；24 组组合成绩链接、3 条待补全记录、2 条实际 0 分。

| 功能/现象 | 具体查看方式 |
| --- | --- |
| 长期波动与近期下降 | 题型分析 → 英语 → 阅读理解：近三场较此前三场回落 |
| 总体改善但过程反复 | 英语 → 完形填空：有提升，也有多次回落 |
| 基础题反复失分 | 物理 → 快速提分：选择、实验均有反复失分 |
| 难题、小分值失分 | 数学 → 按题型 + 位置 → 高分突破：第 21 题场均失分较少，第 22 题更突出 |
| 不同难度 | 各题型/位置均显式标注；数学第 19 题近期难度不同，汇总显示「难度不一」 |
| 人工原因标注 | 展开「查看最近标注」可见标注条数；编辑考试可查看逐条内容 |
| 成绩下降、排名上升 | 对比 9 月 27 日周练二与 10 月 1 日国庆联考，总分下降但年排从 102 到 88 |
| 排名、位比 | 六科考试有年排/班排、总分市区排名；英语百分制小测直接录入位比 |
| 均分与组合 | 六科考试有各科、总分、语数外、科学组合的班级/年级均分与组合排名 |
| 原始分与赋分 | 化学原始分与最终分不同；生物原始满分 100、最终满分 70 |
| 部分题型覆盖 | 10 月 10 日语文缺古诗词题型，科目总分仍完整 |
| 未录入与 0 分 | 生物、物理小测、英语待补录有未知分数；化学实验、数学压轴小问有实际 0 分 |
| 不同满分与单科考试 | 「专项小测」分类有英语百分制、物理半卷、数学 15 分专项 |
| 隐藏考试 | 「专项小测」数学：勾选包含隐藏考试可见压轴专项 |
| 考试详情、反思 | 六科考试有起止日期、考后记录，详情可比较前次考试 |
| 目标与倒计时 | 目标合计 612，示例院校与 2027-01-15 期末目标日期 |
| 完整指标/低信息负担 | 默认显示重点数字解读、历史图表与失分结构；完整指标及口径可展开 |

题型分析只做数据展示、解读与视角排序，不提供具体学习行动建议。AI 识图和 AI 单题分析应通过真实上传资料触发，不伪造模型报告、识别历史或用户互动。

种子脚本 `design/showcase-question-types.cjs` 生成可审查 SQL；仅按精确用户名 showcase 更新确定的演示记录和演示目标。运行前校验同 ID 记录归属与演示标记，不修改原有 12 场考试。测试使用独立 PostgreSQL，验证重复执行不增加重复记录。
