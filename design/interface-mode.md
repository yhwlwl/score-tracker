# 简单与完整模式

独立分支 `feat/simple-full-mode-20261029`，基于 main，和外观分支可单独评审。默认保持完整模式，已有用户不会突然丢失入口。入口在页面顶部的模式按钮，以及账号页的「使用模式」。偏好按账号存于当前设备；退出/切换账号不会复用另一账号的模式。

| 范围 | 简单模式 | 完整模式 |
| --- | --- | --- |
| 导航 | 概览、记录、账号 | 原有四个导航入口 |
| 首页 | 最近成绩、基础趋势、最近考试 | 原有全部卡片和图表 |
| 考试录入 | 得分、满分为主；目标、原始分、排名、均分收进补充信息 | 原有全部字段 |
| 当前考试 | 可单独「显示完整录入」 | 完整录入 |
| 设置 | 安全、科目、分类、外观、公告、数据工具常驻；其他可展开 | 全部设置 |
| 分析 | 首页提供切换完整模式的入口 | 原有完整统计分析 |

模式只改变呈现，不删除/禁用输入、不清空筛选和成绩数据、不改后端。表单展开和模式切换保留同一批输入节点。已有补充信息有提示；保存仍经过原有验证和 API 路径。全局从统计页切到简单模式时返回概览，已有考试编辑器打开时保持编辑器不重建。

新增 `interface-mode.js` / `.css` 为独立资源，构建脚本更新指纹，Cloudflare 构建也包含资源。`/mode-qa/` 使用隔离的合成数据，不连接真实账号。

验证：`design/test-interface-mode.cjs` 覆盖导航/卡片显示、账号隔离、刷新、取消、存储失败、未保存输入节点、0 分、原始分、排名、手动总分的真实保存请求。浏览器补充检查手机与桌面布局及交互。

2026-10-29 复核：完整模式恢复分析导航、雷达图和交流设置；保持原有字段和保存请求。新分支承接原模式实现，替代旧模式草稿分支。
