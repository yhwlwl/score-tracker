# 试卷复盘：核对后的分析更新

本轮在 PR #40 的 `52b2c25` 上继续修改，不新增数据库迁移，不修改核心成绩记录。

## 行为变化

- 分别判断作答、批改分和题意。第二次未读到分数或选项时保留第一次有效读取；两次明确读取冲突时保留候选并询问具体内容。没有批改分的可读作答仍可分析。总分冲突不再清空所有逐题批改分。
- 报告先展示结论、成功步骤和具体任务。移除空诊断/空解答/未评价难度的占位段落，把一般资料说明和判断依据放入可展开区域；真实分数或选项冲突仍有明确标记。
- 增强图示箭头、累计距离、手写运算、跨对象证明衔接和运动阶段切换的检查要求。主断点简洁展示，但分析须覆盖影响后续小问的状态与边界。
- 每题可提供最多三个小问任务，各自有任务 ID、操作和验收标准。综合报告选择任务并排序，按来源保留内容，合并重复任务，避免不同标题被替换成同一句建议。
- “保存并更新分析”对改动的作答、批改分、满分或考试回忆重新分析相关题目，再重新生成整体建议。只勾选核对/订正不调用模型。仅根据保存的文字与用户补充更新，不重新读取已丢弃的原图；首次转录另行保留。
- 更新期间保留上一版报告并标明状态。失败后保留原报告和核对记录，可以继续更新。所有权、版本和阶段令牌控制重复请求；每份报告最多五次分析更新，核对记录始终可保存，重试沿用原有两次上限。
