# Live metrics contract

The database migration `centenary_live_metrics_only` extends the existing service-role-only `score_tracker_centenary_data(uuid)` RPC. It refreshes exact shared aggregates on demand after 60 seconds (transaction advisory lock shared with manual publishing), returns live_award_count and personal_measured_at, and preserves the frozen publication and eligibility fields. It never invokes the publication function, creates awards, changes armed or schedules cron. The normal status endpoint and preview endpoint retain session-derived user identity. The rate counts actual triple awards belonging to current ordinary users over current ordinary users. UI polls at 60 seconds while the celebration/award dialog is open, and 120 seconds otherwise, and refreshes on visibility/online. The publication cohort and publication timestamps remain unchanged. The preview must never create an award or fake a grant. Verify SQL permissions, no cron activation, unchanged publication flags, and a fresh data timestamp.
