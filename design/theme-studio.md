# 成套主题与装扮

入口：账号 → 外观主题 → 设置外观。基于 PR #47，分支 `feat/theme-studio`。

## 素材库版（2026-10-28）

参考 QQ 的分类浏览和大图试用交互，背景使用 3 张 Unsplash 摄影素材与原有纹理。按最新反馈撤掉实验性的立体挂件，恢复原有 24 个线条挂件、24–40px 尺寸与紧凑选择器。素材全部自托管，图库缩略图与实际壁纸分别加载。来源见 `assets/themes/ATTRIBUTION.md`。设计过程中生成的概念图没有用于当前素材库。

- 推荐、背景、挂件、卡片、字体、收藏六个分类；背景按风景/简约纹理筛选。
- 手机以素材浏览为主，点选后展开可收起的实时效果区；可进入当前实际页面试用。使用中、试用中和待试用有独立状态，保存按钮明确提交当前整套设置。
- 挂件默认不启用；选择后仅点缀每页第一张卡片，支持手动指定、独立大小和位置。已经保存的实验性立体挂件迁移为不显示，其他外观设置不变。
- 背景、预览和缩略图都指向同一素材；浓度滑块实时生效。正式成绩卡片保留实底。

- 六套配套主题：云间天蓝、方格笔记、薄荷花园、晨光奶油、星河夜读、复古手账。背景、底色、卡片和挂件一起应用，字号沿用当前阅读习惯。
- 六张原创 SVG 背景，可独立选择并调整浓度；四种卡片样式：纯净、柔光、描边、纸张。
- 24 个原创 SVG 挂件。全局设置左右位置和大小，逐卡装扮可独立覆盖挂件、位置与大小，并恢复跟随全局。
- 正文五种选择；标题七种选择。新增霞鹜文楷、朱雀仿宋、得意黑、站酷快乐体，后两种仅用于标题。所有字体自托管，完整字体按需加载，预览用独立小样本，缺字使用系统回退；来源和许可见 assets/fonts/README.md。
- 预览不写入已保存设置。支持撤销、取消/Escape、恢复默认和保存；最多收藏八套搭配。存储失败保留弹窗和预览，允许取消。偏好仅存当前设备，没有增加后台接口。

`st_studio_v1` 是原子保存的外观偏好，包含基础配色与阅读设置副本；`st_studio_saved_v1` 保存收藏。旧配色与字体控件继续可用。按有限预设白名单、数值范围和卡片键验证存储内容，收藏名称始终转义。装扮修改不会请求成绩数据；仅在账号页保存时重新渲染，逐卡修改保留当前页面内容。

背景与装饰均由本站提供，没有图片/字体 CDN 或运行时主题库依赖。装饰不拦截点击，打印时隐藏。趋势折叠按钮与挂件独立占位，只有顶部标题预留空间，避免首页主标题变窄。

## 验证

- `design/test-theme-studio.cjs`：实际生产脚本，覆盖六套主题、24 个挂件、预览/取消/Escape/撤销、保存与重载、收藏与名称转义、逐卡覆盖/独立大小/继承、原有控件兼容、异常与被禁用的本地存储。
- `design/test-appearance.cjs`：七套基础配色 × 五种正文 × 三档字号、页面切换、刷新、重置、输入防御与字体文件。
- 雷达图选择、密集趋势和分析导出回归；bundle 语法、资源指纹及 Cloudflare 构建。
- 浏览器检查手机 320/390、平板 768 和桌面 1280 的选择页与实际页面，含深色统计页、仿宋正文、得意黑标题和大字。布局检查使用浏览器实际 DOM 尺寸，图表的必要容器内滚动保留。浏览器模拟尺寸不等同于全部实机与系统字体验证。

## 免登录预览

`/appearance-qa/` 使用实际应用资源和隔离的合成数据。顶部可以选择页面、尺寸、主题、正文和字号。已保存的搭配随页面切换；此页不读取登录凭证或真实成绩。直接预览：`/appearance-qa/frame.html?studio=1&page=appearance`。

重新生成：`node design/build-bundles.js && node design/build-appearance-visual.cjs`。

## 现成插画素材（2026-10-29）

新分支 `feat/appearance-assets-20261029` 基于 `feat/theme-studio`。新增 Craftwork Open Stickers 的12款插画贴纸，按插画贴纸/经典线条浏览；保留24款原有线条。插画40–72px（默认56px），线条24–40px。透明WebP合计约104KB，无运行时外部素材请求。来源和独立许可见 assets/themes/ATTRIBUTION.md。

新增花间晴日/月色窗边两套背景，采用上述现成插画与渐变组合；图库、预览和页面共用素材与定位。预设默认不自动添加卡片挂件。DrawKit风景包下载链接实测404，未集成未取得的素材。

回归覆盖新贴纸保存/刷新、大小、经典挂件切换、旧偏好、取消还原、资源指纹和Cloudflare打包。

## 精细场景与角色挂件

按用户反馈重新制作两幅完整插画「樱风书屋」「星海夜航」及四款透明挂件「书香小猫」「月光小狐」「花园小熊」「云海来信」。通过内置 image_gen 生成，不使用第三方同人/游戏/QQ原画。保留提示词与素材来源说明。

精选两套主题包含一款配套挂件，仅应用每页首张卡片，可单独关闭。挂件80–120px、默认96px；选择页两列大图。经典线条与旧简约贴纸仍可选择；上版两张图标拼贴背景保留偏好兼容，但退出推荐和图库。新增完整背景查看弹窗，不保存或改变当前试用；页面顶部留出少量场景空间，成绩卡片保留可读实底。

## 轻盈背景与简笔角色挂件

按最新提供的小马、小狗参考降低视觉复杂度。两幅背景改为 `*-v2.webp`：春日窗景保留一枝樱花、晴空与远湖，月夜保留弯月和云海，大部分画面留白。原画查看、缩略图和实际页面共用新版素材，主题 id 保持兼容。

默认「可爱挂件」为马上上岸、小狗打招呼、趴书小猫、晚安小狐，采用简单轮廓、平涂色块和少量点缀；前两款按用户上传参考重绘，后两款遵循相同复杂度。挂件96–144px宽、默认112px，横向比例，不添加界面投影。原24款线条与12款简约插画可选，上版复杂挂件保留已存偏好兼容，不再进入推荐列表。配套主题分别使用简笔小猫、小狐，仅装饰首卡。

## 马上上岸成套主题（2026-10-30）

`study-shore` 是围绕已有上岸小马精修的成套搭配：晴空、晨光与开阔湖面，右侧岸边小路向远处延伸；天空和水面留白，细节集中在下缘。背景由内置 image_gen 原创生成竖版及同场景横版，900px起使用横版，避免桌面裁切掉湖岸。完整原画查看同步切换对应画幅。

统一奶油白卡片、深蓝绿色文字/按钮、鼠尾草绿选中态与导航，正文和标题使用系统字体，字号沿用用户偏好。保留小马原素材，默认112px，仅点缀首卡。推荐页首幅横向主题封面可一键试用整套搭配，背景分类中仍支持单独选择。主题配色跟随事务保存、取消和撤销，离开主题时恢复基础配色，无全局残留。
