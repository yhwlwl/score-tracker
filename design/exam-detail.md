# 单次考试详情

考试记录中的每一场考试增加“查看详情”，保留编辑、隐藏、删除和排序。详情页属于考试记录导航，按整体概况、各科成绩、四象限、已录入试题排列；返回时恢复列表位置。隐藏考试也可查看，内容来自该考试已保存的数据。

## 数值口径

- 手动总分优先显示，不假设加权规则或满分，不推算总得分率。
- 自动总分只合计计分科目；缺分时标为“已录入科目小计”，待全部出分才显示总得分率和总目标差。
- 最终分和原始分分列。只有满分一致时沿用原始分作为最终分，并标明来源；零分保留。统计项不计总分，也不参加四象限。
- 各科年级、班级排名独立展示。位比优先采用录入值，否则为名次 / 参考人数；与原有录入口径一致，科目人数空缺时使用本场考试总人数。无人数不推算位比；名次大于人数时提示核对。
- 组合使用成员完整最终分合计，组合排名使用已录入的组合排名，保持原有本机缓存兜底。平均分复用 `ScoreAverages` 的科目与满分一致性校验。

## 四象限

在同场考试、同一排名范围内，筛选同时有有效得分率和位比的计分科目。至少两科才能显示。横轴是得分率减去参与科目的等权平均得分率，纵轴是平均位比减去该科位比（正值代表排名更靠前）。中心始终为 0，可切换年级和班级，不改动首页或趋势图的筛选状态。

| 位置 | 分组 | 解释 |
| --- | --- | --- |
| 右上 | 优势巩固 | 得分率较高、排名较靠前 |
| 左上 | 抢分突破 | 排名较靠前、卷面有相对更多失分 |
| 右下 | 竞争提升 | 得分率较高、排名相对靠后 |
| 左下 | 优先补强 | 两项都相对靠后 |

均值线上的科目标为“接近均值”。同坐标科目不偏移真实数值，逐科按钮可分别查看。该图只说明本次考试的相对科目表现，不推断试卷难度、长期能力或历史进退。未参与科目列出缺失原因。

## 试题入口

调用现有 `list_all` 按 `exam_id` 分页读取已提交的录入与分析记录，按科目筛选已加载记录。“查看录入的题”在本次考试内直接打开已有报告并定位到题目；也可查看整体分析、核对文字和原始扫描件。没有已提交记录时，提供现有考试编辑 / 试卷录入入口。云端未提交草稿仍在 AI 分析工作台管理。

读取和查看不调用开始分析、恢复、计次或成绩保存接口；报告中的主动核对/恢复保留原有行为。进入详情的账号和 token 始终绑定，导航或账号切换后丢弃旧请求；报告若已关联到其他考试，要求刷新。离开有未保存核对修改的报告时保留原有确认。

## 验证

`design/test-exam-detail.cjs` 用实际前端 bundle 和实际试卷 Edge handler，连接隔离的合成数据，验证入口、隐藏考试、完整/缺分/零分/原始分满分不一致、手动总分、均分、组合、四象限分组、范围切换、51 份试卷分页、已有题目定位、无新增分析计次、未保存修改、读取失败重试与导航/账号隔离。

移动端用两列指标和逐科卡片，四象限与科目解释上下排列。JSDOM 检查功能和 DOM；不将其表述为真实浏览器的手机/桌面截图验收。
