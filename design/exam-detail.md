# 单次考试详情

考试记录中的每一场考试增加“查看详情”，保留编辑、隐藏、删除和排序。详情页属于考试记录导航，按整体概况、各科成绩、四象限、已录入试题排列；返回时恢复列表位置。隐藏考试也可查看，内容来自该考试已保存的数据。

## 数值口径

- 手动总分优先显示，不假设加权规则或满分，不推算总得分率。
- 自动总分只合计计分科目；缺分时标为“已录入科目小计”，待全部出分才显示总得分率和总目标差。
- 最终分和原始分分列。只有满分一致时沿用原始分作为最终分，并标明来源；零分保留。统计项不计总分，也不参加四象限。
- 各科年级、班级排名独立展示。位比优先采用录入值，否则为名次 / 参考人数；与原有录入口径一致，科目人数空缺时使用本场考试总人数。无人数不推算位比；名次大于人数时提示核对。
- 组合使用成员完整最终分合计，组合排名使用已录入的组合排名，保持原有本机缓存兜底。平均分复用 `ScoreAverages` 的科目与满分一致性校验。

## 四象限

默认视图为“排名与变化”，纵轴显示本次排名位比（越上越好），横轴显示位比变化（右进步、左退步）。纵轴以本次有效计分科目位比的中位数划分个人相对强弱，横轴以 0 为界。纵轴根据当前科目的位比范围调整刻度，避免排名靠前的科目全部挤在顶部；每个刻度始终标明实际位比。至少有两科当前位比和一科可比历史才能显示。

比较口径：

- 默认“较上次可比考试”：变化 = 历史位比 − 本次位比，单位为百分点。
- 可切换“近3次趋势”：本次及之前两次可比记录，按考试序号拟合位比斜率并取反，单位为百分点/场，不按间隔天数拟合。
- 历史只选更早日期、相同分类、相同科目、同一排名范围的有效位比。已隐藏考试和不计总分的历史统计项排除。按日期寻找，不使用手动记录顺序；同一天不推断当前考试的先后，每个历史日期最多取一次（先取创建时间较晚、再按 id 确定顺序的有效记录）。
- 参考人数变化时依旧按位比比较，年级和班级不混用。只有排名没有分数也可参与。缺少有效历史时列明原因，不补 0，不标为持平；近3次不足时不自动降级为上次比较。
- 点选科目显示当前排名与位比、变化值、参与计算的考试名称、日期和原始名次/人数。变化四舍五入到 0.01 个百分点后为 0 时视为基本持平；位于当前位比中位数的科目也标为临界。

| 位置 | 分组 | 解释 |
| --- | --- | --- |
| 右上 | 优势上升 | 当前排名相对靠前、最近进步 |
| 左上 | 优势回落 | 当前排名相对靠前、最近回落 |
| 右下 | 弱科改善 | 当前排名相对靠后、最近进步 |
| 左下 | 优先关注 | 当前排名相对靠后、最近回落 |

原“得分率 × 排名”保留为“本次表现”视图，仍按有效得分率和位比的等权均值分界，保留优势巩固、抢分突破、竞争提升、优先补强分组。均值线上的科目标为“接近均值”。两种视图均可切换年级和班级，不改动首页/趋势图的筛选。视图切换不请求后台、不修改考试数据。相同坐标不偏移真实数值，逐科按钮可分别查看；未参与科目列出原因。不将相对强弱解释为试卷难度或长期能力。

## 试题入口

考试详情可独立使用。未加载 AI 试卷模块时，仅展示考试概况、各科成绩和四象限，不展示试题入口，也不请求试卷接口。加载 AI 模块后自动启用下列已有试题入口；对应联动测试随 AI 分析 PR 提供。

调用现有 `list_all` 按 `exam_id` 分页读取已提交的录入与分析记录，按科目筛选已加载记录。“查看录入的题”在本次考试内直接打开已有报告并定位到题目；也可查看整体分析、核对文字和原始扫描件。没有已提交记录时，提供现有考试编辑 / 试卷录入入口。云端未提交草稿仍在 AI 分析工作台管理。

读取和查看不调用开始分析、恢复、计次或成绩保存接口；报告中的主动核对/恢复保留原有行为。进入详情的账号和 token 始终绑定，导航或账号切换后丢弃旧请求；报告若已关联到其他考试，要求刷新。离开有未保存核对修改的报告时保留原有确认。

## 验证

`design/test-exam-record-view.cjs` 在仅有考试查看的前端中验证查看入口、隐藏考试、各科成绩、均分与组合、缺分/零分/不同满分/手动总分、返回与账号切换；确认没有 AI 依赖时不会展示失效入口或请求试卷接口。

`design/test-exam-detail.cjs` 用实际前端 bundle 和实际试卷 Edge handler，连接隔离的合成数据，验证入口、隐藏考试、完整/缺分/零分/原始分满分不一致、手动总分、均分、组合、四象限分组、范围切换、51 份试卷分页、已有题目定位、无新增分析计次、未保存修改、读取失败重试与导航/账号隔离。

`design/test-exam-quadrants.cjs` 验证默认排名变化视图、四个方向、个人中位数分界、参考人数变化、直接位比、只有排名无分数、严格日期/分类/范围匹配、历史隐藏/统计项/缺人数排除、近3次趋势的数值与不足提示、零位比/真实持平/重叠点、旧表现视图和全局筛选隔离。

移动端用两列指标和逐科卡片，四象限与科目解释上下排列。JSDOM 检查功能和 DOM；不将其表述为真实浏览器的手机/桌面截图验收。
