# `/mg` 管理面板需求核对

核对日期：2026-08-28

本文按《Score Tracker 后台管理面板完整设计方案》逐项检查。状态含义：

- 已完成：当前版本可以直接使用。
- 部分完成：界面和降级状态已完成，但仍受现有数据接口限制。
- 后续数据工程：必须先建立新的数据库聚合口径，前端不会用近似值冒充正式指标。

## 验证记录

- JavaScript 语法检查通过。
- Cloudflare 部署目录构建通过，`api/mg-ui.js` 已进入部署产物。
- 桌面 1280px 视口逐页检查六个模块，无控制台错误。
- 移动 390px 视口检查用户页和侧栏菜单，无页面级横向溢出。
- 用户详情、反馈会话、日志证据、筛选、分页和 URL 状态已交互验证。
- `score-tracker-admin` 边缘函数已更新“最近”时间范围查询。
- 用户列表已切换到数据库侧全量聚合 RPC，访问日志已切换到服务端分页接口。
- 管理后台首次加载后的查询结果按参数在当前页面会话内缓存；刷新按钮仍会强制重新读取。
- 反馈状态和管理员回复会等待请求完成后保留当前会话，不自动关闭反馈详情。
- 总览访客指标采用 24 小时窗口，在线指标采用 5 分钟窗口；避免未使用的历史全量去重扫描阻塞页面。
