# 成绩含金量：统一的个人历史参考尺子

## 定位与可识别性

问题：同样的个人排名表现，在不同试卷上会得到不同分数；相邻排名匹配无法覆盖大量记录。目标是用完整历史建立可计算、一致、可更换参照的尺度，而非寻找历史例子。

只有一个人的分数与排名，无法识别整张试卷的真实难度，也无法完全拆开题目难度、个人状态、群体变化和内容变化。本模型估计的是**以排名为表现代理的个人相对难度偏移**，不声称实现正式等值、IRT/Rasch 参数估计、真实能力测量或群体难度校准。

页面始终写“相对难度估计”“换算参考分”，保留原始成绩、尺度单位、低支撑警示和局限。小样本可计算但不表现为高精度已校准结论。

## 来源与建模方案

- 现有 app-v34 的 PAL 内核提供 inverse-normal 变换；独立模块有 normal-CDF 数值逆解 fallback。
- 分数取单科最终分数 actual、满分 max。科目人数为空时回退该场总人数；科目排名绝不回退总排名。显式无效人数/位置不回退。
- 同分类内按日期排序；相对该阶段此前人数中位数，人数差异 / 两者较大值达到 30% 时开启新阶段。同科目、同分类、同阶段共用模型；不同阶段和科目不可直接比指数。
- 至少 3 场有效的成绩、满分、日期、年级排名位置与整数参考人数（≥30）建立模型。未分类只与未分类比较。不同满分允许进入模型，以得分率统一。
- 重复 ID 保留最终提供的记录，不因重复增加支撑场数；无 ID 使用日期、名称和分类识别重复。缺失、无效和计划中未录成绩的考试不参与。
- 这是回顾性描述模型：使用当前已录入的完整记录，包括显示考试本身以及其后已录入的考试；回看旧考试不是重放当时的预测。取消一年/相邻位比窗口限制。

考察过的方案：邻近排名匹配缺覆盖；直接按排名比例放大分数没有测量依据；高阶拟合容易受稀疏历史/外推影响；真正试卷等值需要群体分布或共同题目等数据。本版采用两个参数的稳健单调关系与一个有明确含义的偏移坐标，避免把推断指数直接加在卷面分上。

方法参考（仅支持基础方法与边界，不构成对本产品模型的外部验证）：

- ETS, *Equating Test Scores (without IRT), Second Edition*: https://www.ets.org/Media/Research/pdf/LIVINGSTON2ed.pdf 。正式等值需要关于参考人群的设计与信息，个人等值并不可直接实现。
- Statsmodels Robust Linear Models / Huber M-estimation: https://www.statsmodels.org/stable/rlm.html 。本产品实现采用稳健损失思想，并额外限制斜率非负、限制高杠杆点影响；并非照搬 statsmodels 或宣称使用其软件验证。

## 定义与公式

对每场 e：

1. 展示位比为名次/人数。拟合时用 `edge=max(0.5/N,1e-8)`、`p = clamp(pos/100 - 0.5/N, edge, 1-edge)` 做连续性修正并防止极端人数的数值溢出，`z = Φ⁻¹(1-p)`；z 越大排名表现越靠前。这只是排名的坐标变化，不是已测量的正态能力分。
2. `y = logit(clamp(actual/max, 0.005, 0.995))`，处理不同满分并确保反变换有界。零分与满分内部用边界修正，明确降低支撑评价。
3. 拟合 `y ≈ a + b z`，`b ≥ 0`。Huber IRLS 最多 24 次，常数 1.345；尺度 `max(0.03, 1.4826*MAD(residual))`，另有由 z-MAD 得出的杠杆权重，避免极端排名独占拟合。
4. 将难度偏移中心设为这组完整记录的平均：
   `d_e = b*(z_e - mean(z)) - (y_e - mean(y))`。
   同排名预期下分数更低 → d 更大（相对偏难信号）；整组 d 的算术平均恰为零。
5. 展示指数 `D_e = 100*sigmoid(d_e)`。0–100 为显示坐标，不是概率；50 对应平均偏移零。平均难度要先平均 d，再变换为 D，不能直接平均展示的指数。

参照集合 R 的平均偏移 `d_R = mean(d_e, e∈R)`。

换算：`y_ref = y_current + d_current - d_R`；`score_ref = M_ref * sigmoid(y_ref)`。

等价式是 `y_ref = mean_R(y) + b*(z_current - mean_R(z))`。这表明换算参考主要表示“本次排名，在参照尺度上常见的成绩”，不能把它解释成一个独立的真实能力测量。实际分用于确定本场难度偏移；难度与能力不能在单人数据里被完全独立识别。

这套偏移坐标保证参照差的方向一致、在同一模型中差值可相加、同一考试参照自己保持原分。d 没变时按相同比例转换满分，避免零分/满分内部修正破坏恒等性。任何换算都落在 0 到目标满分之间。

## 三种参照

- **历史平均**：该模型组中全部有效记录，等权平均难度偏移（包括本次）；参照指数为 50，按本次满分显示。
- **一段时间**：用户选定起止日期，闭区间，使用该模型组期间全部有效记录，包括范围内的本次；按本次满分显示。无记录或日期无效不自动改用其他参照。
- **某次考试**：选该模型组的一场记录；使用它的难度偏移与满分。同一场参照自己是恒等结果，即使缺少建立模型所需的历史，也不虚构难度。

参照期可以只有一场，但明确提示个人状态影响和支撑较弱。不是要求参照期单独拟合新模型，而是从同一把完整历史尺子中取偏移，因此切换参照不会改变本次难度指数。

## 稳定性与局限

少用一场历史记录重拟合斜率，并在相同完整数据中心和固定参照集合上重算结果。至多 80 次、均匀抽取要略去的记录；页面显示这些结果与主估计的最小/最大值。

这是**斜率对样本选择的敏感范围**，不是置信区间、预测区间，也不覆盖参考人群变化、个人失常、单场难度估计本身等不可识别的不确定性。即使范围窄，也不能断言真实难度准确。

以下情况展示“先作参考”并用日常语言就近说明：少于 8 场；排名变动很少（z标准差<0.15）；稳健斜率非正；残差MAD尺度>0.5；敏感范围宽于满分的10%；零分/满分边界；参照只有一场。历史少时直接展示可比较记录场数，并提示把分数当作大致参考；不能因为敏感范围窄就消除弱支撑提醒。

若历史分数与排名呈负关系，非负约束让斜率为0，换算接近参照集合的平均 logit 得分率；页面明确说明此时排名调整关系较弱，不能把结果当成可靠难度校准。这些门槛是产品支撑规则，不是经过真实用户群体校准的统计置信等级。

相同人数不保证相同人群；同分类也不保证相同知识范围。赋分制度改变、走班、学校/班级变化以及能力与试卷难度随时间共同变化，都可能干扰关系。目前只按已录入数据设边界。未来如有群体均分、标准差、分数分布或共同题目，才可建立更强的校准。

## 展示与联动

- 保持位置：分析页概览后、趋势图前。实际成绩与换算分并排；科目、本次考试和三种参照使用已有主题控件。
- 主卡以实际分/换算分为核心，只保留一句结果和必要的一条短提醒（如“仅7场记录，先作参考”），页脚一句“估算仅供参考，实际成绩不会改变”。删除重复标题标签、引言、默认可见的难度三格及多段解释。
- “参考考试”与“怎么算的？”独立折叠，默认都关闭。前者直接显示考试表，不带前后说明段落；后者包含本次/参照难度、场数、算法定义、限制和去一场重算范围，明确结果相近不代表准确，也不是下次考试的分数范围。限制原因仍在估计附近简短提示，不只隐藏到方法中。
- 考试表保留考试、日期、实际分/满分、年级排名/人数、难度指数，并可直接将一场设为参照。长列表限定高度，手机可横向查看，无长图或缩放变形。
- 全量矩阵保留原始表现/难度参考切换，后者与卡片调用同一模型。难度用固定0–100连续色阶，主题面板底色到主题强调色等比例混合（8%–92%），不按每行或当前数据范围重缩放；图例标明0、50平均、100。黑/白文字按实际底色选择较高对比度，主题修改会刷新当前格子与图例。缺失为无色的“—”，不伪装成零难度；弱支撑格子用†并在图例旁解释，完整原因在点击后的卡片与无障碍名称中可查。难度不估算总分，因此不保留一列空总分。
- 两个矩阵视图共用固定136px考试列和76px科目列，考试名最多两行，完整原名保留在文本、title与点击后的考试选择中；日期另占一行。首列与科目表头固定，表格独立横纵滚动（移动端最多420px高），保留全部考试，不压缩字号、不拦截页面触摸事件；滚动区可以键盘聚焦。原始表现里的逐场异常圆点仍由 PAL 序贯难度信号提供；用途与回顾性统一尺子不同，不伪称两套算法完全同源。
- 不将各科指数简单平均成总分难度；组合筛选只限定单科可选范围。不同组指数只能在各自参考范围内解释。
- 数据与算式在客户端计算；模型按输入签名缓存，更新分数/排名/人数等会失效。大历史敏感性重拟合最多80次。

## 埋点

复用 __stTrack：score_worth_view、score_worth_selection、score_worth_reference_mode、score_worth_reference_selected、score_worth_matrix_metric、score_worth_matrix_open、score_worth_evidence_open。两处折叠区的展开来源分别为records/method，均有埋点，替换卡片后重新绑定。版本2记录参照类型、结果类型、模型/参照场数、支撑级别和操作来源；不上传分数、排名、指数、科目/考试名称、日期、记录 ID 或证据表内容。无额外成绩接口或数据库迁移。

## 验证结论及未验证范围

design/test-score-worth.cjs 共21组检查，包括独立给定已知难度与排名的交叉模拟：检查拟合斜率、偏移方向、0–100指数和参考分；72→88具体参照；无邻近排名仍计算；不同满分；日期闭区间；原分恒等和偏移可加；异常值；弱/负关系；跨分类/换池；无效/重复/缺失；缓存；输入排序；210场规模与敏感性上限；实际bundle页面三参照、矩阵同尺子、过滤、焦点、主题、曝光及脱敏埋点。新增小样本文案与折叠说明、0–100色阶单调性和黑白文字对比度（每个索引/六种主题色组合≥4.5:1）、主题变化刷新格子与图例、54场矩阵完整性及长名称/缺失/固定列/键盘结构检查。

数值与已检查DOM流程可交付，须保留估计假设。模拟结果只能验证在给定假设下的算式与实现，未使用真实用户样本校准难度准确性；没有实测群体难度标签。当前浏览器运行环境不可用，手机/桌面真实视觉与手势验收仍未完成，DOM/CSS检查不代替实机验收。
