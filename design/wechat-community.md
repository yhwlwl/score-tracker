# 微信交流群

## 使用与发布

- 管理后台新增「交流群」，维护群名、介绍、原图二维码、北京时间到期时间和可选的微信官方 HTTPS 链接。默认关闭，没有二维码不能启用；保存使用版本检查，避免覆盖其他管理员的新设置。
- 个人页在账号卡片下方单独显示「交流与反馈」，不挤入赞赏入口、不自动弹群邀请、不影响原有反馈功能。点击后重新读取配置，再展示放大、保存二维码与操作说明。
- 到期、关闭、未登录或配置读取失败均隐藏入口。退出账号清除已读配置和面板；请求结果校验账号与请求代次，避免串号。
- 公告与更新编辑器提供「插入交流群介绍」，写入介绍和 `[查看交流群](#community)`。前台将其转为安全按钮，先关闭更新弹窗，再读取当前群配置；历史更新也使用当前二维码。未开放时按钮隐藏。不提供任意 HTML、外链图片或通用图文编辑器。
- 新版本说明中可使用后台的一键插入介绍；本次不自动发布或改写现有线上更新日志。
- 新配置表仅服务端可读写，开启 RLS 并撤销公共客户端权限；公共加群读取也要求有效的现有账号会话。二维码限 PNG/JPEG/WebP 原图 350 KB，禁止 SVG、外站图片和任意跳转协议；不记录群成员或扫码结果。
- 入口显示、从个人页或更新日志打开、关闭、二维码放大/缩小、保存请求、官方加群链接点击、二维码加载失败和配置读取失败均通过现有埋点通道上报；不上传二维码内容、群名、介绍或链接地址。

## 验证

`design/test-community.cjs` 覆盖实际通知处理器鉴权、管理员保存、二维码与链接校验、到期隐藏、并发保存冲突、个人页、更新弹窗交接、二维码放大、异常回退及账号退出。`design/test-community-migration.cjs` 使用 PostgreSQL 验证默认配置、RLS 和权限。回归已有赞赏与通知测试。

新增迁移与通知 Edge Function 是独立的、默认关闭的兼容扩展；前端和后台页面随 PR41 合并发布。真实群二维码待管理员上传，不使用测试二维码替代上线。
