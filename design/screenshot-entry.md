# 截图与题型得分录入

录入只定位题号、题型、原题/作答区域与已有批改分、印刷满分。原题和作答使用保存的扫描区域展示，不转录题干、选项、公式、答案，不判分、不生成分析。

- 每次仅处理当前页，每个阶段只发送当前整页总览或一个待补读局部，截图边界使用该视图的明确坐标；DeepSeek 关闭思考，输出上限 8192。先处理原卷，再按目录匹配答题卡。参考答案仍可保留查看，无需为此调用模型。
- 每页结果写入 `analysis_state.scan_pages` 后再推进。中断保留已完成页，恢复仅处理未完成页；逐页继续执行仍校验会话、归属、指纹、claim 和计费预算。
- 页面显示当前试卷/答题卡第几页、已处理/总页数、已定位题数、两类截图均已定位的关联题数、带有效依据且无冲突的批改分数目；无推算百分比或虚假模型内部进度。
- 同题跨页合并区域，分数读数冲突保留 null，不能覆盖旧读数。未知不当零；得分和满分必须保留对应数字依据。无可靠坐标保留页码供手动框选。
- 明确的题型合计在覆盖题号与该题型成员完全相同、成员均已确认后，可用于题型汇总；不摊分、不与逐题合计重复累计。题型名称或范围不一致时不套用。
- 旧版在 extract 失败且尚无有效目录的任务，可通过“继续录入”切换新流程，即使旧转录恢复次数已耗尽。已有成功记录与历史分析保持原内容。
- 正式 12 级等级、150/400 分开始余额、按 token 用量结算和预算限制沿用当前 PR；本次只更新 PR 及独立预览函数，不替换现有生产函数。

验证：`node design/test-screenshot-entry.cjs` 覆盖逐页失败恢复、零分/未知/冲突、单页模型输入、关闭思考、实际进度、截图关联、题型合计去重及旧任务恢复。发布检查入口已纳入该套件。真实图片定位准确性和耗时以新版上传实测为准，不以模拟测试替代。

本轮补齐：题型合计的未知题号不被过滤后误用；部分逐题分数大于题型合计时保持待补全；跨页题型名冲突与得分大于满分均标记。未匹配作答保留所有候选作答页供手动框选，新增/删除区域后立即刷新核对状态，重新打开时沿用已保存区域。公开合成预览同步使用截图核对模式，`?progress=1` 可查看标明为合成数据的进度界面。

## 通用坐标定位 v2

- 上传时在浏览器生成整页与重叠局部视图，按长宽比分成横向条带、纵向条带或四个重叠区域。覆盖每个像素，不假设题号、栏数或学科；原始扫描件不加网格，坐标网格仅出现在模型视图。
- 模型输出明确的 `view_xyxy_1000` 左上/右下坐标，新增请求统一要求 `v0` 整页坐标，局部视图仅用于读数与内容完整性核对；既有局部坐标仍利用保存的裁剪范围兼容换算。格式、范围、视图不存在等错误明确保留为核对项，不猜单位、不静默丢框。
- 选择题共用填涂区可显式关联多个实际题号；跨页/跨栏内容保持多框。满分与批改分沿用已有证据规则，不因坐标修改而自动判分。
- 视图裁剪范围随私有图片一起保存、恢复与校验。旧记录和断点兼容原坐标格式，不篡改用户手工区域。
- 本地新增验证覆盖多种长宽比的完整覆盖、局部坐标映射、共用区域、未知题号、越界/格式错误、旧记录和私有视图元数据保存恢复。
- 真实样本基线：2026-11-15 成功数学录入共4张试卷、2张答题卡、19题、约60秒，3题缺少原题框，12题缺少作答框。视图方案仍需真实模型复测，不能把几何回归等同于定位准确率。
- 后续用户明确授权使用真实数学/物理资料复测，使用有时限和独立强令牌的临时接口；调用走共享预算的测试账目，不消耗用户个人积分，不覆盖原记录或手工框。
- 模型图片请求改为对当前用户已保存的当前页签发10分钟私有链接，避免把多张base64图片重复塞入请求。链接在调用模型前逐个检查可读性，再用于当次模型输入，不写入指纹、检查点或报告；客户端不能指定待签名路径。
- 模型明确返回图片下载失败时，当前页最多重试一次；权限、积分、预算等错误不作此重试。图片输入统计区分内联图片字节和授权链接数。
- 真实复测需要逐页查看原图叠框，题号数量不能代替框选准确性；跨页选项、长题全部小问/附图、多栏作答、细小批改分与合计都纳入人工核对。

## 内容行定位

- 整页模型视图添加蓝色 L 行号；行范围由像素墨迹投影得到，排除长横线、长竖线与孤立噪点，不做OCR、不依赖题号或卷面模板。原始扫描件保持原样。
- 模型选取每题起止行，服务端按保存的实际行范围换算截图上下边；行号缺失或越界须修复响应，不能将估计坐标冒充准确边界。没有可用行带的图片与旧记录保留原坐标流程。
- 行元数据随局部视图保存、恢复、旋转重建和指纹校验；客户端新加字段必须通过长度、范围、有序性验证，不能携带任意URL。

- 印刷框候选通过容许轻微倾斜的长边检测产生，去除跨栏合并候选；只有模型确认该完整框只属于同一题时才使用。小型横向答题表格可自动增加最多两张放大图，所有模型视图仍最多6张。没有可靠边线时退回普通框选，不假设固定栏数。

- 每次模型调用只发送一个视图。整页先定位，小型答题格和长答题框的题头分值按需单独补读（最多5个），避免同一响应漏看细小批改分。补读使用明确的局部坐标再换算回原图，和整页读数冲突时保留待核对。
- 每个整页/局部结果均保存检查点；补读失败后只恢复未完成局部，整页不重跑。进度额外显示正在补读第几个小型答题区，成功推进后重置当前阶段的恢复次数。所有标尺数字放在外侧留白，避免遮挡卷面小字和分数。
