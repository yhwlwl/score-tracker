# Score Tracker 成就徽章系统 v1（开发稿）
## 目录与口径
51枚：普通6、稀有8、史诗11、传说13、至臻7、限定6。唯一目录为 `supabase/functions/_shared/achievement-catalog.js`，包含名称、条件、稀有度、历史模拟人数（参考分母9895）、获奖文案、徽记、证据类别、隐藏标记和发放方式。比率为此前不同时间历史回放的参考值，不是当前真实发放比例；旧快照分母略有差异。推算比例不等同于学生能力。功能上线较晚的温故知新仍为普通。等级永久固定，不按实时获得率自动改级。不设学生排行榜、不设置每日签到压力、无强制分享。
- 预测突破阈值以实际回测为准：1/3/5个不同考试日超越2pp，10个不同考试日超越5pp；不是此前HTML里的3次超越5/10pp。
- 按总分科目组合、考试分类、相近参考人数构造可比序列，单科得分率只比较同科同满分；最小历史数据足够支持算法即可，难度来自成就条件本身。时间类按不同考试日或真实上传日定义。
- 历史回放与考前真实预测严格区分。当前自动扫描保存历史回放证据，不宣称是当时已展示或冻结的预测。真实预测快照表已准备，实际写入/匹配与使用仍是下一阶段工作。
- 独一无二只在真实相似轨迹预测快照和结果匹配上线后开启；限定活动与贡献须审核，不信任浏览器上报。最初的同行者可按注册日期判定。二期9枚（目标快照、反思链路、长期使用等）暂不计入。
## 视觉与交互
共用六级金属/珐琅/晶面/金色/虹彩/青绿框架，51枚独立SVG主题纹样；图形不依赖外部资源。普通与稀有轻动画，史诗/传说/至臻层次化辉光与揭晓动画，限定独立纹样；收藏馆不持续闪烁。系统减少动效设置生效。双面卡正面获奖语言与稀有度、历史回测参考比例；背面条件、真实证据、来源标记，按预测点、区间、状态、雷达、难度、时间轴等选择图表。无真实证据不捏造；预览一律标注模拟。隐藏成就仅在UI未获得时遮挡（不是安全机密，静态目录可被开发者查阅）。批量首次回放合并成一次弹窗，按代表徽章展示，可进收藏馆查看其余。关闭后才记录回执。用户可随时关闭，账号切换清空内存缓存。
## 运行方式
- 独立预览 `achievement-preview.html`，不需要登陆、不请求生产API。仓库根目录启动任意静态HTTP服务；支持随机、筛选和全量巡展。
- 服务端默认关闭：只有在测试项目迁移并验证后，设置 `SCORE_TRACKER_ACHIEVEMENTS_ENABLED=true`，才开启正式入口和授予。没有生产迁移、部署或授予操作。
- API 继续使用现有自定义 session 校验，查询严格限制 user_id；RLS 和 grants 拒绝公开直接访问；award唯一键、冲突忽略、冻结证据、独立已读时间，自动扫描冷却60秒。录入、登录、目标或反思成功后的刷新与原成绩保存隔离。
- 真实线上开放前：测试数据库执行迁移/回滚检查、验证RLS及跨账户隔离、真实浏览器手机/桌面/暗色/减少动效、数据量与CPU压力测试、导入与账号恢复/转移策略、真实预测快照写入及核验限定发放；与其他尚未合并的PR协调。当前单次扫描最多10000行每表，超过会明确报错而非发放不完整结果；长序列性能待验证。

## 真实账号预览（不发放）
独立预览提供全部演示及真实账号两种模式。复用现有登录、list_exams、get_goal接口，只在浏览器内计算真实记录，不调用奖项写入接口。现有登录可能替换旧会话；预览不将密码或新token持久化，退出清空内存。现有API未返回注册日期时早期限定标记待核验；活动/贡献和匹配快照暂不猜测。现有记录接口达到1000行上限时停止计算。全站比例仍为历史回测，不是发放比例。

## 正式收藏馆布局
账号信息与安全设置之间使用代表徽章入口；独立自适应收藏馆，手机全屏，桌面宽布局。我的珍藏最多三枚（正式版账号级服务端持久化，预览仅内存），我的收藏 / 全部成就 / 成就历程，按月份和日期分组、同日合并。徽章详情使用独立 dialog 返回原浏览位置。日期来自条件证据，不伪造未知时间；历史时间是现存记录推算的达成参考，尚未证明真实首次达成或当时已录入。正式获得率通过服务端每日首次访问刷新聚合快照，排除管理员及明确已知的演示账号 showcase/admin/admin1，其他测试账号待进一步确认。预览保留历史回测参考且不调用正式写接口。迁移和全流程测试后才可开启。
