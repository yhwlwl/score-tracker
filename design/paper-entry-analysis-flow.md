# 试卷复盘：上传 → 核对 → 看结果

PR54 承接 #40、#43、#46，包含试题录入、独立 AI 报告、题型录分与长期统计。主入口统一为「成绩分析 / 题型分析 / 试卷复盘」，旧的 AI 路由兼容进入试卷复盘。已同步 main 的备份导入、稳定公告编号、开发者评论与 #56 组合识图修复。

## 用户流程

1. 「试卷复盘」以一份原始录入为一张卡片，关联报告归到同一份试卷。进入后用「试题与得分 / AI 分析」切换；旧版独立报告与原始录入已删除的报告仍可阅读。列表按原始编号归组，不凭相同考试、科目或名称合并不同上传。
2. 「上传试卷」选择科目与可选考试。从考试编辑页进入时自动带入上下文；试卷名称自动生成。试卷、答题卡与参考答案最多15张，参考答案默认折叠。上传页不展示分析设置，识别与生成分析各消耗一次的规则提前显示。保留草稿、原图、作答位置及同一请求重试能力。
3. 识别后先看题数、缺失/冲突数量、已对照原卷数量和明确的卷面总分。题目行显示题型、得分与待核对原因；可筛选需要核对、未对照原卷或全部。缺失与冲突项默认展开，正常题目默认阅读，点击修改才展开编辑框。没有异常不等于用户已经核对；修改题型、文字、得分、满分或难度后撤销该题的已核对标记。
4. 页面下方直接汇总本科题型，修改即时反映。可以「只保存试题」，也可以「保存并更新题型得分」。后者先保存核对、再向后端取最新预览并条件更新；已有题型必须明确确认替换，后台出现新增记录或并发编辑时要求重新核对。没有关联考试时不写入考试。未知得分和满分保持 null，0分保留；未分类题排除、未核对的分类题阻止更新；不完整题型保存为待补全、不进入统计。仅替换本科题型，不改整科、总分、原始分、赋分或其他科目。
5. 「生成 AI 分析」会先保存未保存的核对修改，再进入简洁配置页。默认显示分析范围、特别想问的问题与明确计次的开始按钮；讲解详略、模块、运行上限、年级、已学范围、原图与历史成绩选项收在更多设置。默认启用优势、难度、错因、解答与跨题共性，练习和复习安排可选。本设备按账号记住已成功提交的偏好，不记住题目、个人提问或同意勾选。同一请求重试不重复计次。
6. 分析从已录题目与核对结果开始，不重新识别目录或匹配作答。可复用私有原图理解图形，也可只用文字。报告首屏展示总览、优势、主要问题与下次考试注意点；难度明细、问题依据、练习安排与原始资料默认折叠，目录点击会自动展开并定位。逐题内容始终可访问。

## 数据与边界

- 继续使用现有试卷、扫描件和修订字段，无新增数据库结构。
- 列表只增加源编号的 JSON 投影，不下载整份报告来归组。正在运行的报告从 analysis_state 读取源编号；已完成报告从 result 读取。按源编号过滤同样限制当前账号，支持分页。
- 每份分析保存源编号、修订及独立文字快照。修改原始录入不修改旧报告；删除分析保留原录入与扫描件，删除录入后仍保留报告文字与已更新题型分。
- 题型得分保存失败不触发模型；分析新建与识别各计一次，查看、核对、题型更新不调用模型。
- 同步先保存试题，再更新题型，属于两个独立操作：题型更新失败时已保存试题保留，并明确提示未更新成功；不宣称跨表整批回滚。

## 验证与发布

`design/test-paper-record-flow.cjs` 验证实际前端 bundle 与隔离 Edge handler 的完整链路，包括归组、源过滤、旧入口、人工核对、清空分数、零分、替换保护、保存后分析、报告导航及权限边界。沿用原有评分、恢复、原图、计次、题型、成绩导入及组合识图回归。

免登录演示位于 `/design/paper-record-flow-qa/`，明确使用合成数据、模拟请求，不写入真实账号。分支更新后由 Pages 自动发布预览；生产前仍需部署配套 `score-tracker-paper-review` 后端。不能用仅通过前端部署代替后端上线。

真实整卷识别准确率和耗时仍需用授权样本复测；此前约125秒目录阶段超时不在本次声称已修复的范围内。
