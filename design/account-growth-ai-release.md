# 试题录入、账号成长与 AI 积分：发布说明

本文件描述 PR #54 的最终上线范围。PR 阶段只修改代码与合成数据预览，**不合并 main、不应用生产迁移、不部署生产 Edge Function、不开启生产预算**。旧的 `paper-entry-analysis-flow.md` 中开放完整分析、按次数扣额度的内容由本文件替代。

## 当前开放范围

- 成绩图片识别：提取单科、组合分、排名与已明确标出的题型。
- 试题录入：提取题目与参考答案、读取学生作答与批改、核对题号与资料、补读批改分。最多 15 张资料。
- 核对：批量确认无异常题，保留缺失、冲突、低置信度等异常；支持撤销。原题和答题卡区域关联、放大与手动调整，坐标校验后保存在原私有资料中。
- 只保存试题，或核对后同步题型；保留零分、未知值、整科成绩及其他科目，版本冲突不覆盖。
- 已有报告仍可读取。新诊断、AI 判分、汇总分析、局部重分析、旧任务的分析恢复均在服务端关闭；内部 worker 也检查阶段白名单。`diagnose` 仅作为录入结束时本地组装结果的边界，不能调用模型。
- 查看、人工编辑、保存与题型统计不请求模型。服务就绪检查同样不请求模型。真实连接测试和管理员测试请求模型，计入全站预算，个人积分为 0，保留限流。

首次体验目录：记录成绩 30，快速录入后实际保存 10，趋势 15，雷达 15，含金量 20，轨迹匹配 20，目标 15，考试反思 15，题型统计 20，核对试题 20，查看已有分析报告 20，导出 10，应用外观 10，反馈/投票 10，学习规划预留 10。目录合计 240；规划暂缓，不因点击站外链接发放这 10 分；新分析不开放但可查看自己的已有报告。

- 每个有效使用月 +60；单纯登录/刷新/心跳不计入。
- 新增不同考试日期，每个 +20，每月最多 3 个；重复添加同一日期不重复奖励。空考试、只填目标、未来日期不算。
- 结合自己有效考试查看趋势/雷达/含金量/匹配或考试详情：每个功能、考试、月份只记一次 +5；每场每月最多 +10，全账号每月最多 +20。
- 有效反馈被管理员采纳后，可由管理员主动调用 `growth_contribution`（`feedback_id`）奖励 +20；同条一次、账号累计最多 100。仅 `planned/resolved` 的本人反馈可奖励，不能由普通用户授予。
- 正常业务保存不因成长服务短暂失败而失败；下次查询账号会按持久数据补记。埋点使用服务端时间和已验证的账号，不能传入任意积分/历史时间。

## AI 积分与成本

首次加入一次性 150 分；没有 1,500 分赠送，也没有额外全流程分析体验。记录第一场有效考试即可进入 Lv.2，领取当月额度。旧识图次数只保留历史，不折算为新积分。

等级月积分自动累计，无需领取或每天打开。上限 `max(3000, 月积分×3)`；升级当月只补月额度差额。长期未打开时按已获得等级的旧月额度补齐至余额上限，历史月份不会追溯套用今天升级后的高额度。初次创建钱包只发当前月，不补上线前的历史月积分。

标准用量定价：1,000 分对应 1 元模型标准成本。以 2026-11-14 核对的 DeepSeek Flash 高峰价计：每百万输入未命中 2 元、缓存命中 0.04 元、输出 8 元。思考已包含在输出，缓存属于输入，均不重复累计。参考官方定价：<https://api-docs.deepseek.com/quick_start/pricing>；上线前按实际使用的模型、上游及代理加价复核。

`积分 = (未命中输入×2 + 命中输入×0.04 + 输出×8) / 1000`。

| 操作 | 旧样本标准成本，无缓存折扣 | 个人额度规则 |
| --- | ---: | --- |
| 成绩图片识别 | 约 ¥0.0122 / 13 分 | 至少可用 13 分，最多预留 150 分 |
| 仅提取题目和参考答案 | 单轮约 ¥0.1203 / 121 分 | 开始需 150 分，最多预留 1,000 分 |
| 读取作答与批改 | 单轮约 ¥0.1086 / 109 分 | 包含在同一录入任务，不额外收取固定次数费用 |
| 核对材料 | 旧阶段累计约 ¥0.1587 / 159 分 | 按实际各轮用量结算 |
| 完整录入及作答核对 | 预算参考约 400 分起 | 开始需 400 分，最多预留 1,000 分 |
| 补读批改分 | 旧样本单轮约 ¥0.0062 / 7 分 | 同一任务实际累计 |
| 用户连接测试 / 管理员模型测试 | 按原始 usage 入账；缺失则未知 | 不扣个人分，仍占共享预算并限流 |
| 新试卷分析、AI 判分、汇总、局部重分析 | 当前不开放 | 不得请求模型 |

上述是历史阶段参考，不是新版独立流程实测或固定承诺。各阶段样本不同，不能把均值当成同一份试卷的真实合计。提交成功才将整个任务的已知用量汇总、向上取整一次，个人扣款不超过批准的预留。失败释放个人预留、扣 0 分；平台已经产生的费用仍记账。个人预留 45 分钟后可释放，**上游未知费用不随时间释放**。

所有模型 HTTP 请求先写持久化预留再发出。每轮保存原始 usage、缓存命中/未命中、输出/思考、供应商请求号和响应状态。缺缓存字段时保留 NULL 并按全部输入未命中保守计算；兼容 `prompt_tokens_details.cached_tokens` 和仅返回未命中量。缓存数据相互矛盾时不享受缓存折扣。

每轮记录价格快照，改配置不会重算旧请求。个人积分只按标准费率；全站预算再乘管理员配置的上游成本倍率，覆盖代理加价。只有明确配置的 Flash 模型别名可请求；其他模型先拒绝，不能落到未计价通道。

## 全站预算与异常处理

- 每个北京时间自然月，已知费用加未结算预留共用 15 元预警、20 元硬上限。后台可以降低预算，不能通过界面提高到 20 元以上。
- 每轮预留按照已配置模型最多 100 万输入 token 和请求的 `max_tokens` 计算最坏费用，使用全站月预算行锁防止并发透支；并非只检查历史平均费后放行。
- 真实调用超时或响应无 usage，保留全额全站预留。可能在实际消费远低于 20 元时提前停用，这是预算保护，不是把未知账单写成 0。
- 后台展示已知费用、待结算费用、未决调用及供应商请求号。管理员核对上游明细后使用 `ai_usage_reconcile`（`call_id`、原始 `usage`、可选请求号和状态）结算；幂等，不自动推断缺失用量为零。已完成或失败的任务不因事后补账向用户追扣。
- 同账号至少间隔 15 秒、最多两个进行中任务；连接测试保留独立日限流。旧的成绩识图阶梯次数和试卷每日次数不再作为用户权益限制。
- 数据库所有新表启用 RLS，无浏览器角色策略；所有相关 RPC 仅 service_role 可执行，沿用已验证的自定义会话。账号删除可正常进行，金融调用留匿名任务和月成本，不因删除记录重置预算。

## 验证边界

`npm ci --prefix design --ignore-scripts` 后运行 `node design/run-release-checks.cjs`。CI 不含生产凭据，仅运行隔离 PostgreSQL、Edge handler、JSDOM 和本地构建检查。当前包含 14 个上线范围套件，以及账本的 75 项断言；旧完整分析的启用态测试保留供未来恢复时复审，不作为当前开放能力。

Deno 对共享计费模块、模型运行时、录入 worker 及识图恢复器的类型检查通过；所有修改涉及的 TypeScript 可解析。完整入口类型检查因环境无法获取 `jsr:@supabase/functions-js` 的远程声明而未完成，不将此写为通过。前端构建和真实浏览器 320/390/768 与桌面检查通过；等级、用量记录、批量确认/撤销、异常跳过与关联截图可查看。

公开预览只包含自编合成试题和模拟扫描图，所有 `/api` 请求在浏览器内模拟，不调用 AI、不写生产。没有将历史真实用户试卷、账号或调用日志放入公开预览。
